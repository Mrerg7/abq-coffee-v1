# ABQ.Coffee

Informational static site for an Albuquerque coffee brand concept.

**Domain available for acquisition** → [sales@desertrich.com](mailto:sales@desertrich.com)

## Stack

- Astro 5 static · Tailwind · TypeScript · Cloudflare Workers Static Assets
- Hero video via Cloudflare Stream

## Deploy

- **Build command:** `npm run build`
- **Deploy command:** `npx wrangler deploy`
